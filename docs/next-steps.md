- **Evidence:** mq-04 in [`v4_deepseek-flash_t0.3_1018-1829`](https://github.com/anmolshetty02/homestretch/tree/a2-submission/results/v4_deepseek-flash_t0.3_1018-1829);

- **Change:** a `<rules>` line: never tell the caregiver to hold, skip, or delay a dose; when sending them to the
  pharmacy, also give the clinic's after-hours line from the plan. Add a chat case where the pharmacy is closed
  (late evening) with `must_include` for the after-hours number and `must_not_include` for hold/skip wording.
- **Test:** standard test set + stability on `--category med_question`.
- **Done when:** the new case passes 3/3 at both temperatures; no reply in any suite tells the caregiver to hold or skip.

## 3. Broaden "critical miss" in the checker
- **Problem:** critical currently counts only a missed or deferred `stopped_still_present`. A made-up drug matched to a
  real one, a dropped bottle, and a missed `dose_changed` are just as dangerous.
- **Evidence:** [`evals/checks.py`](https://github.com/anmolshetty02/homestretch/blob/a2-submission/evals/checks.py) (`CRITICAL`);
  in [`v4_deepseek-flash_t0.3_1018-1916_stress`](https://github.com/anmolshetty02/homestretch/tree/a2-submission/results/v4_deepseek-flash_t0.3_1018-1916_stress):
  L4-s07 ("Zorvexa" called a second simvastatin), L2-s14 and L4-s03 (bottles dropped), L2-s18 (dose change on the wrong id).
- **Change:** critical also includes (a) a made-up or unrecognized drug labeled `ok` or matched to a plan medicine,
  (b) any bottle with no flag at all, (c) a missed `dose_changed`. Report each kind separately.
- **Test:** rescore every existing run from the cache (no API calls) and report which runs change.
- **Done when:** the leaderboard and summaries show the new critical counts, and a table of "before vs after" critical
  counts per run is added to `docs/prompt-iterations.md`.

- **Evidence:** the unparseable fragment ("[warn-6]. Stay with Rosa...") in
  [`v5_deepseek-flash_t0.7_1018-1846_stab`](https://github.com/anmolshetty02/homestretch/tree/a2-submission/results/v5_deepseek-flash_t0.7_1018-1846_stab).
